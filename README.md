# 矿山管理系统简版

独立简版从 `lite/` 目录重新制作，不复用原系统页面和脚本。

## 首页与端口

- [简版首页：七个工作端口入口与入职二维码](lite/index.html)
- [入职信息登记表](lite/enroll.html)
- [管理员后台](lite/management.html)：首次设置本地演示密码后，可审核入职申请并管理车数、人员、车辆和物资
- [管理端员工工作页](lite/manager-work.html)：管理端员工审核通过后的独立入口
- [Boss 端](lite/boss.html)：Boss 本人设置独立本地演示密码后进入
- [功能树与变更记录](功能树.md)

首页已建立以下入口：司机端、挖机端、辅助司机端、调度端、管理端、Boss 端、中层管理端。新入职人员选择端口后填写登记表，首位管理员需先在审核用浏览器设置密码，再让员工使用同一浏览器提交演示申请；管理员可通过或驳回申请，管理端员工审核通过后进入独立工作页。Boss 不走入职登记和管理员审核，由 Boss 本人在当前浏览器首次设置独立演示密码后进入 Boss 工作台占位页。

当前功能为可交互原型，档案和领用记录保存在当前浏览器。人员登记表含国籍、民族、证件及银行信息等字段；班组可选生产A组、生产B组、行政办公组、修理组，国籍选填。该公开演示页面请勿录入真实敏感信息。手机扫码与管理员审批尚未实现跨设备同步；管理员和 Boss 的本地演示密码分别保存在各自浏览器，不构成真实安全保护，也不能跨设备共享。
