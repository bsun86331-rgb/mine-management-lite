# 矿山管理系统简版

独立简版从 `lite/` 目录重新制作，不复用原系统页面和脚本。

## 首页与端口

- [简版首页：七个工作端口入口与入职二维码](lite/index.html)
- [入职信息登记表](lite/enroll.html)
- [管理员后台](lite/management.html)：首次设置本地演示密码后，可审核入职申请并管理车数、人员、车辆和物资
- [管理端员工工作页](lite/manager-work.html)：管理端员工审核通过后的独立入口
- [功能树与变更记录](功能树.md)

首页已建立以下入口：司机端、挖机端、辅助司机端、调度端、管理端、Boss 端、中层管理端。新入职人员选择端口后填写登记表，管理员首次在当前浏览器设置密码后可通过或驳回申请；管理端员工审核通过后进入独立工作页。演示流程仅在同一浏览器中生效。

当前功能为可交互原型，档案和领用记录保存在当前浏览器。人员登记表含国籍、民族、证件及银行信息等字段；班组可选生产A组、生产B组、行政办公组、修理组，国籍选填。该公开演示页面请勿录入真实敏感信息。手机扫码与管理员审批尚未实现跨设备同步；本地演示密码不构成真实安全保护。
